Vocabulary studies

Five visual languages, one identical scene (same targets, same class, same panels). Judge the feeling, not the content. Grounded in current dev-tool design research: elevation-by-lightness, one-accent discipline, tabular numerals, ≤150ms hover feedback, cockpit color rules. ⌘K works in each.

V1 · Flux

Linear/Raycast-grade minimalism. Zinc surfaces, elevation by lightness, one electric-indigo accent, spacious padding, 200ms ease-out everything. Command palette open on load.

Feels like: the tool you trust all day. Risk: safe to the point of bland.

V2 · Phosphor

Modern terminal romance — Warp/Charm lineage. Mono-first everything, block panels, phosphor green with disciplined glow on exactly two elements, blinking cursors, ASCII tree guides.

Feels like: hacker identity, in-group pride. Risk: mono UI labels tire some users.

V3 · Flight Deck

The literal captain's cockpit. Titled instrument bays, aviation color discipline (red = errors only), HUD telemetry strip with Zulu clock, toggle switches, 90ms instrument response.

Feels like: commanding the target. Risk: density can read as cold.

V4 · Blueprint

The contrarian light mode — engineering schematic. Warm paper, ink hairlines, construction grids, renames shown as drafting redlines, annotation-style panel titles. Dark toggle included.

Feels like: a precise printed schematic. Risk: light mode is heresy to some.

V5 · Ultraviolet

Synthwave cool, disciplined. Deep-space indigo, frosted-glass panels over a slow ambient aurora, UV→cyan gradient on focus signals only, magenta reserved for the agent. The "I want to live in this tool" option.

Feels like: cinematic identity. Risk: the aurora must stay out of working surfaces — if it ever distracts, it's slop.

V6 · Helio

The hybrid: V3's flight-deck rigor (HUD strip, instrument bays, toggle switches) on V4's blueprint paper palette — flat, no grid textures — with V2's phosphor glow confined to live elements (LEDs, clock, current line, blinking cursor). Red reserved for redlines and warnings.

Feels like: a precision instrument on bright paper. Dark toggle included.

V7 · Helio, docked

V6 evolved to close its gaps: a real docking system (drag tabs between dock and rails, layout presets Default/Wide/Debug, ⌘J/⌘B collapse), a first-class LIGHT/DARK switch with light as default, and a strict Okabe–Ito signal palette in both themes.

Feels like: the V6 instrument, now rearrangeable and color-blind safe.
Research basis: Linear's motion tokens & perceived-speed doctrine, Raycast's action-bar teaching, Warp/Ghostty terminal-modern palettes, aviation HUD color discipline (≤6 colors, red reserved), OKLCH elevation-by-lightness, APCA contrast comfort, "hacker flavor at 5%, not 50%". These vocabularies are orthogonal to the layout — any of them can skin the Workbench A2 design.
