⚙ LLM PROVIDERS
the endpoints missions run on — label, baseUrl, model list, LOCAL (loopback, no key), API key. Keys are write-only (never displayed, stored chmod 600 in backend/.workbench/llm-keys.json); a key can also come from the server's environment as WORKBENCH_LLM_<ID>_KEY, which wins over the stored one. Which model a task uses is picked elsewhere: NEW MISSION or ⚡ REVERSING AGENT.
One provider per vendor/endpoint — its key lives here. Add model versions to the provider's list and mark the default.

⚡ REVERSING AGENT
the built-in routine behind right-click → ⚡ Reverse and the RELATION button — which model runs each depth, how hard it thinks, where it stops. The model has no default: an unconfigured depth spawns nothing. Effort, turn cap and budget blank = the depth's default.
